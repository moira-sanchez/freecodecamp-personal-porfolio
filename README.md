#  Mi Portafolio Personal

Este proyecto consiste en la creación de un portafolio personal para presentar algunos de mis proyectos realizados durante mi aprendizaje de desarrollo web.

La página incluye una sección de bienvenida, una sección de proyectos y enlaces que permiten acceder a las páginas en vivo o a los repositorios de GitHub.

## Proyectos incluidos

- Kamisama Kiss
- Link Click
- Inventario de libros
- Página de cartas
- Otros proyectos personales

##  Tecnologías utilizadas

- HTML
- CSS

##  Características

- Barra de navegación fija
- Sección de bienvenida
- Tarjetas para presentar proyectos
- Enlaces a proyectos y repositorios
- Diseño responsivo mediante Media Queries
- Enlace al perfil de GitHub

Este proyecto fue realizado como parte de los laboratorios de Responsive Web Design de freeCodeCamp.
